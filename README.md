# bottg
# Документация Telegram-бота «Дневник головной боли»

**Версия:** 1.0  
**Тип:** Telegram-бот для ежедневного самонаблюдения  
**Назначение:** спрашивать пользователя о головной боли, сохранять записи, напоминать о воде и выдавать общие немедикаментозные рекомендации.

> ⚠️ Бот не является медицинским изделием, не ставит диагноз и не заменяет врача.  
> Все рекомендации носят информационный характер.  
> При сильной, внезапной или необычной боли — обратиться за медицинской помощью.

---

## 1. Цели и задачи

Бот должен:

1. Раз в день спрашивать пользователя, болит ли у него голова.
2. Записывать данные: интенсивность, длительность, симптомы, триггеры, лекарства, количество воды.
3. Напоминать пить воду в течение дня.
4. Давать общие советы, которые могут помочь облегчить состояние.
5. Показывать историю и статистику.
6. Предупреждать о «красных флагах», когда нужно обратиться к врачу.
7. Давать возможность экспортировать и удалить данные.

---

## 2. Пользовательские роли

- **Пользователь** — обычный человек, который ведёт дневник головной боли.
- **Администратор** — следит за работоспособностью бота, смотрит логи, не имеет доступа к медицинским записям без согласия пользователя.

---

## 3. Основные функции

### 3.1. Ежедневный опрос

Бот отправляет опрос в выбранное пользователем время.  
Пример вопросов:

1. Болит ли голова сегодня? `Да / Нет`
2. Если да — интенсивность по шкале `0–10`.
3. Локализация: лоб, виски, затылок, вся голова, с одной стороны, другое.
4. Характер: пульсирующая, давящая, сжимающая, ноющая, другое.
5. Длительность: `<30 мин`, `30–120 мин`, `2–4 ч`, `4–24 ч`, `>24 ч`.
6. Сопутствующие симптомы: тошнота, светобоязнь, звукобоязнь, аура, головокружение, нет.
7. Возможные триггеры: недосып, стресс, голод, обезвоживание, погода, экран, алкоголь, менструация, неизвестно.
8. Принятые меры или лекарства — текстом.
9. Сколько воды выпито за день — примерно в мл или стаканах.
10. Комментарий — свободный текст.

### 3.2. Учёт воды

- Команда `/water` записывает 1 стакан воды по умолчанию, например 250 мл.
- Можно указать объём: `/water 300`.
- Бот напоминает пить воду каждые N часов в заданном интервале.
- Напоминания можно отключить.

### 3.3. Советы при головной боли

Бот не назначает лекарства. Он может предложить общие меры:

- выпить стакан воды, если нет противопоказаний;
- отдохнуть 15–20 минут в тихой, затемнённой комнате;
- сделать перерыв от экрана;
- проветрить помещение;
- при необходимости приложить прохладный или тёплый компресс;
- не пропускать приёмы пищи;
- выспаться;
- избегать известных триггеров;
- лекарства принимать только по назначению врача.

**Логика по интенсивности:**

| Интенсивность | Рекомендация |
|---|---|
| 0–3 | Отдых, вода, перерыв от экрана, проветривание |
| 4–6 | Тихая тёмная комната, компресс, вода, сон, наблюдение |
| 7–10 | Не заниматься самолечением, обратиться за медпомощью |
| «Красные флаги» | Срочно обратиться к врачу или вызвать скорую |

**Красные флаги:**

- внезапная «самая сильная боль в жизни»;
- боль после травмы головы;
- температура + скованность шеи;
- нарушение речи, зрения, слабость, онемение;
- спутанность сознания, обморок;
- боль длится более 72 часов без улучшения;
- новая боль у человека старше 50 лет;
- беременность, онкология, иммунодефицит.

### 3.4. История и статистика

- `/history` — последние 10 записей.
- `/stats` — статистика за 7 или 30 дней:
  - количество дней с головной болью;
  - средняя интенсивность;
  - частые триггеры;
  - среднее потребление воды;
  - динамика.

### 3.5. Напоминания

- Ежедневный опрос — по умолчанию в 20:00 по часовому поясу пользователя.
- Напоминания о воде — по умолчанию каждые 2 часа с 9:00 до 21:00.
- Пользователь может изменить время, интервал и отключить напоминания.

### 3.6. Настройки

Команда `/settings`:

- часовой пояс;
- время ежедневного опроса;
- включить/выключить напоминания о воде;
- интервал напоминаний;
- начало и конец интервала напоминаний;
- формат экспорта: JSON / CSV.

## 5. Пользовательский сценарий

1. Пользователь запускает `/start`.
2. Бот показывает дисклеймер и просит согласие.
3. Пользователь выбирает часовой пояс и время опроса.
4. В заданное время бот спрашивает: «Болит ли голова сегодня?»
5. Пользователь отвечает.
6. Бот задаёт уточняющие вопросы.
7. Бот сохраняет запись.
8. Бот даёт рекомендации и напоминает про воду.
9. В течение дня бот отправляет напоминания о воде.
10. Пользователь может посмотреть историю, статистику или экспорт.

---

## 6. Пример диалога

**Бот:** Добрый вечер! Болит ли голова сегодня?  
`[Да] [Нет]`

**Пользователь:** Да

**Бот:** Оцените боль от 0 до 10.

**Пользователь:** 5

**Бот:** Где болит?  
`[Лоб] [Виски] [Затылок] [Вся голова] [С одной стороны] [Другое]`

**Пользователь:** Виски

**Бот:** Сколько воды выпили сегодня?

**Пользователь:** 3 стакана

**Бот:** Записал.  
Сегодня: боль 5/10, локализация — виски, вода — около 750 мл.  
Рекомендации: выпейте стакан воды, отдохните 20 минут в тихой комнате, сделайте перерыв от экрана. Если боль усилится или появятся неврологические симптомы — обратитесь к врачу.

## 7. Архитектура

**Компоненты:**

- Telegram Bot API;
- backend: Python 3.11+, `aiogram 3.x`;
- база данных: PostgreSQL;
- планировщик: APScheduler или Celery Beat;
- кэш/очереди: Redis;
- контейнеризация: Docker + Docker Compose;
- мониторинг: Sentry, Prometheus/Grafana.

**Схема работы:**

```text
Telegram → Bot API → Backend → PostgreSQL
                         ↓
                    Scheduler
                         ↓
                 Напоминания и опросы
```

## 11. Безопасность и приватность

- Данные о здоровье — чувствительная категория.
- Бот запрашивает явное согласие до начала сбора данных.
- Пользователь может экспортировать и удалить все данные.
- Данные передаются по HTTPS.
- Доступ к БД ограничен.
- Логи не должны содержать медицинские подробности без необходимости.
- Администратор не должен вручную читать записи без согласия пользователя.
